# AdministraGastos
Repositorio para el proyecto de IV
##Problema
Como estudiante siento que no tengo control en el dinero gastado en comida, asi como que compro cosas que no gasto tanto y no algunas que gasto mas

Para solucionarlo se plantea una aplicacion en la cual se registren los tickets de compra para calcular el dinero gastado asi como los productos para tener un control detllado
de lo gastado, tambien se plantea poder llevar un control de los establecimietos en los que se compra para poder comparar donde es mas barato ciertos productos segun los tickets
